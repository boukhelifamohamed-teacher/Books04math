# نسخة Android — كتب الرياضيات - المتوسط

## بناء APK عبر GitHub Actions
1. ارفع الملفات إلى مستودع GitHub.
2. افتح تبويب Actions.
3. اختر **Build Android APK**.
4. اضغط **Run workflow**.
5. بعد انتهاء البناء افتح Artifacts وحمّل `MathMiddle-debug.apk`.

تم إصلاح أيقونة Android وإضافتها لكل كثافات العرض، مع إزالة الخلفية السوداء الخارجية من صورة الأيقونة.
